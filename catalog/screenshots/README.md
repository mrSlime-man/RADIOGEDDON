# Catalog screenshots

The Apps Catalog requires screenshots taken with qFlipper's screenshot button
on a real Flipper Zero running the Catalog edition (512x256 PNG, only the
colours orange 254,138,44 and black, committed exactly as qFlipper saves them).

None are committed yet: they must come from hardware. Name them `ss0.png`,
`ss1.png`, ... (the first is the catalog preview). `scripts/check_catalog.py`
checks their format and lists them in the generated manifest.

Suggested screens: main menu, Scanner with activity, Receive & Record while
recording, Unknown Protocol Analysis, Pulse Timeline, the Replay screen
showing the region.
