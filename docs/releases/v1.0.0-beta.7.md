## What's new

Research tools for the **Full edition** (RogueMaster, Momentum, Unleashed),
loaded as modules only while in use. The full list is in the
[CHANGELOG](https://github.com/mrSlime-man/RADIOGEDDON/blob/main/CHANGELOG.md).

- **Waterfall** — an RSSI sweep history of the Range Scanner: each complete
  sweep is a row, newest on top, darker for stronger over the noise floor and
  solid over the threshold. Points not measured in a sweep are drawn as their
  own pattern, never filled in. Cursor, peak, scroll back, pause,
  sensitivity, receive at the cursor and CSV export. It is labelled `RSSI
  sweep`: narrowband readings one frequency at a time, not a wideband or SDR
  capture.
- **Bitstream Explorer** — a RAW capture's inferred frames as a frame list,
  bits, bytes from any bit offset, a diff across frames (`.` same, `X`
  changes, `?` too few frames) and a bit field in binary, hex and decimal.
  It shows only what the analyzer inferred.
- **Multi-Capture Compare** — 2 to 8 recordings analysed one at a time into
  a report labelled `[OBSERVED]`, `[HEURISTIC]` and `[HYPOTHESIS]`: frequency,
  preset and timing consistency, identical frames, constant and changing
  bits, and runs that look like buttons or counters. A constant field is
  never called a verified serial.
- **Research Sessions** — named groups of recordings with an active session
  that collects new captures, comparison and report export, and grouping
  *suggestions* that create nothing until confirmed. Sessions never delete or
  move a recording, and an interrupted save leaves the previous version.
- **A grouped main menu**: Scan, Receive & Record, Analyze, Database,
  Sessions, Settings, About. The Catalog edition's menu is unchanged.
- **Modules**: these tools, and Unknown Protocol Analysis, are plugins packed
  inside the Full `.fap` and loaded only while their screen is open. Each
  checks that it fits the free heap before loading and otherwise says `Not
  enough memory`.
- **Unknown Protocol Analysis** (both editions) tells pulse-width codes from
  Manchester by how pulses pair with gaps. It lists every encoding's fit and
  reports how often a pattern repeats within a press. On the firmware's 50
  RAW test captures the encoding is right for 43 (was 41) and the frame
  length for 35 (was 33); Te stays right for 50 and no capture got worse.
  Results stay `[HYPOTHESIS]`.

Transmit rules are unchanged: the Catalog edition checks the firmware's region
before every transmission, and the Full edition relies on the firmware's own
check. Nothing in this release transmits on its own, predicts or decrypts
codes, or recovers keys.

## Which file do I download?

| Firmware | Edition | File | API |
|----------|---------|------|-----|
| Official (flipperzero.one) 1.4.x | Catalog | `radiogeddon-catalog-official.fap` | 87.1 |
| RogueMaster | Full | `radiogeddon-full-roguemaster.fap` | 88.16 |
| Momentum mntm-012 | Full | `radiogeddon-full-momentum.fap` | 87.1 |
| Unleashed | Full | `radiogeddon-full-unleashed.fap` | 88.9 |

Copy it to `SD Card/apps/Sub-GHz/` (replacing beta 6) and open **Apps →
Sub-GHz → RadioGeddon** (Catalog) or **RadioGeddon Full**. The Full edition's
modules are inside the `.fap`; the firmware unpacks them when the app starts.
Full steps: [Installation](https://github.com/mrSlime-man/RADIOGEDDON/blob/main/docs/INSTALLATION.md).

> [!NOTE]
> Momentum and Official both report API 87.1, so the Flipper's version check
> does not tell the two files apart: install the one named for your firmware.

## Build & verification status

- Built from one source tree as two editions for four firmware families, each
  against its own SHA-256-pinned SDK (RogueMaster from its pinned source
  tree). For every artifact the API version, the manifest and every imported
  symbol are verified against that SDK. For the Full builds the same holds
  for each of the five embedded modules.
- 1,962 host unit-test checks under AddressSanitizer and UBSan, covering the
  waterfall history, bit and field extraction, multi-capture comparison on
  synthetic sets with known fields, session files with a failure at every
  save step, and the module size estimate. Also: 654 format checks on the
  firmware's own file code and test files; 289 decoder and preset checks; 354
  checks that score the analyzer on the firmware's captures; 36 engine
  lifecycle checks (the Range Scanner with and without a waterfall); 141
  offline UI checks that draw the screens with the firmware's own fonts on a
  host canvas. libFuzzer runs on the RAW reader, analyzer, Pulse Timeline,
  Database and session files. GCC `-fanalyzer` and clang-tidy report no
  findings, and lint and documentation links are clean.
- The UI previews CI produces are **synthetic renderings** from the host
  canvas, not screenshots of a Flipper; they are not in this release.
- Resident code is 77,173 B for the Catalog edition (beta 6: 75,704 B) and
  104,388 B for the Full edition (beta 6: 94,676 B). Each Full module takes
  2,740 to 16,383 B only while open. Built into the app instead, the new
  tools would have made the Full edition 128,309 B. These figures are measured
  from the built files, not on a device.
- Hardware: not verified for anything new since beta 2. The checks to run are
  in [HARDWARE_CHECKLIST.md](https://github.com/mrSlime-man/RADIOGEDDON/blob/main/docs/HARDWARE_CHECKLIST.md)
  (section B and items M4–M5 are new) and
  [VERIFICATION.md](https://github.com/mrSlime-man/RADIOGEDDON/blob/main/docs/VERIFICATION.md).

## Verifying these downloads

`SHA256SUMS` is attached. Check it with `sha256sum -c SHA256SUMS` (Linux) or the
per-file commands in the installation guide. Each `.fap` also has a signed
build-provenance attestation, checked by the release workflow before upload,
linking it to this release's workflow run and commit:

```bash
gh attestation verify radiogeddon-full-momentum.fap --repo mrSlime-man/RADIOGEDDON
```

`BUILD_INFO.txt` records the edition, app id, SDK, API, source revision and
embedded modules each artifact was built from.

## Known limitations

- Nothing new since beta 2 is verified on a device yet. Radio timing, SD-card
  speed, the firmware's plugin loader and memory headroom on real hardware may
  surface problems the host tests cannot.
- The waterfall measures one frequency at a time: a burst shorter than a
  sweep can be missed on a point the sweep is not visiting. The screen shows
  the sweep time for this reason.
- The Bitstream Explorer's and the comparison's bits are the analyzer's
  hypotheses; the comparison's field classes (button, counter) are heuristics
  and are not verified.
- The Catalog edition is not in the Apps Catalog yet: the submission needs
  qFlipper screenshots from hardware, and it has not been submitted.
- RadioGeddon does not recover keys, decrypt payloads or predict rolling
  codes, and refuses to replay decoded rolling-code protocols.
