## What's new

**Dolphin Lab** — a new interface for the **Full edition** (RogueMaster,
Momentum, Unleashed), built around an original animated dolphin: a lab
engineer with headphones, an antenna and goggles, drawn for RadioGeddon.
The full list is in the
[CHANGELOG](https://github.com/mrSlime-man/RADIOGEDDON/blob/main/CHANGELOG.md).

- **Dashboard home screen** — the dolphin at its desk beside the main menu
  (Scan, Receive, Analyze, Database, Sessions, Dolphin Lab, Settings, About)
  and a status bar with the frequency, preset, radio, active research
  session, a memory warning and the edition. Long OK on Scan opens the
  Frequency Scanner; on Receive it starts receiving and recording.
- **It reacts to what the radio really does.** It watches the radar while a
  sweep collects data, jumps at a real detection or decode, listens while
  receiving, runs the recorder only while the recorder runs (the REC lamp
  follows the recorder itself), works at the terminal during an analysis
  (with a percentage only when the work reports one), cheers at a save,
  worries at an error or low memory, and dozes off after a quiet while — which
  is never read as a radio fault. Repeated events never queue. The radio
  screens' headers carry a small badge with the same state.
- **Three styles** in Settings: *Dolphin Lab*, the technical *Cyber Lab*
  (radar and readouts, only the dolphin's head), and *Classic* — beta 7's
  menus and popups, with nothing of the new interface loaded. Saved with the
  settings; a beta 7 settings file keeps working. No style changes what the
  radio does.
- **Cards** for messages, progress, saves and finished analyses: the same
  text as before (never shortened), with the dolphin beside it when it fits.
  Every message the app shows is checked to fit.
- **Transitions**: short oscilloscope-line wipes into the dashboard, report
  reveals, the Waterfall and the lab room's stations. A key ends one at once;
  they can be switched off.
- **Dolphin Lab room** (main menu → Dolphin Lab): a radar and an antenna
  (illustrations, labelled so; OK opens the real Scanner or Receive), an
  oscilloscope that shows a saved RAW recording's first pulses as recorded, a
  recorder and a terminal with counts read from your SD card, and a gallery of
  every pose. It never uses the radio and is a module loaded only while open.
- **UI feedback** (optional, off by default): *Minimal* vibrates briefly when
  a recording starts and an analysis finishes; *Full* adds short sounds, menu
  clicks and at most one detection blip every 2 s.
- **Both editions**: the Scanner shows which frequency the sweep is measuring
  with a mark under its header.

The **Catalog edition** keeps its Classic menus. Transmit rules are
unchanged: the Catalog edition checks the firmware's region before every
transmission, and the Full edition relies on the firmware's own check.
Nothing in this release transmits on its own, predicts or decrypts codes, or
recovers keys.

## Which file do I download?

| Firmware | Edition | File | API |
|----------|---------|------|-----|
| Official (flipperzero.one) 1.4.x | Catalog | `radiogeddon-catalog-official.fap` | 87.1 |
| RogueMaster | Full | `radiogeddon-full-roguemaster.fap` | 88.16 |
| Momentum mntm-012 | Full | `radiogeddon-full-momentum.fap` | 87.1 |
| Unleashed | Full | `radiogeddon-full-unleashed.fap` | 88.9 |

Copy it to `SD Card/apps/Sub-GHz/` (replacing beta 7) and open **Apps →
Sub-GHz → RadioGeddon** (Catalog) or **RadioGeddon Full**. The Full edition's
modules, including the new lab room, are inside the `.fap`; the firmware
unpacks them when the app starts. Full steps:
[Installation](https://github.com/mrSlime-man/RADIOGEDDON/blob/main/docs/INSTALLATION.md).

> [!NOTE]
> Momentum and Official both report API 87.1, so the Flipper's version check
> does not tell the two files apart: install the one named for your firmware.

## Build & verification status

- Built from one source tree as two editions for four firmware families, each
  against its own SHA-256-pinned SDK (RogueMaster from its pinned source
  tree). For every artifact the API version, the manifest and every imported
  symbol are verified against that SDK; for the Full builds the same holds for
  each of the six embedded modules.
- 2,115 host unit-test checks under AddressSanitizer and UBSan (was 1,962),
  including 150 for the mascot's state machine and the interface's pure
  logic, and a check that the generated sprites match their text art. Also:
  657 format checks (now with beta 7 settings files), 289 decoder and preset
  checks, 354 analyzer checks on the firmware's captures, 36 engine lifecycle
  checks, and 367 offline UI checks (226 new) that draw the dashboard in both
  lab styles for every state, every message on a card, the badges on the
  radio screens, the transitions and the lab room with the firmware's own
  fonts on a host canvas. libFuzzer runs on the RAW reader, analyzer, Pulse
  Timeline, Database, session files and, new, the mascot's event streams, text
  wrapping and the oscilloscope trace. GCC `-fanalyzer` and clang-tidy report
  no findings; lint and documentation links are clean.
- The UI previews CI produces, and the one in the README, are **synthetic
  renderings** from the host canvas, not screenshots of a Flipper.
- Resident code is 77,782 B for the Catalog edition (beta 7: 77,172 B) and
  119,428 B for the Full edition (beta 7: 104,388 B). The lab room module is
  8,830 B and loads only while the room is open; the Waterfall module grew to
  4,315 B. These figures are measured from the built files, not on a device.
- Hardware: not verified for anything new since beta 2. The checks to run are
  in [HARDWARE_CHECKLIST.md](https://github.com/mrSlime-man/RADIOGEDDON/blob/main/docs/HARDWARE_CHECKLIST.md)
  and [VERIFICATION.md](https://github.com/mrSlime-man/RADIOGEDDON/blob/main/docs/VERIFICATION.md).

## Verifying these downloads

`SHA256SUMS` is attached. Check it with `sha256sum -c SHA256SUMS` (Linux) or the
per-file commands in the installation guide. Each `.fap` also has a signed
build-provenance attestation, checked by the release workflow before upload,
linking it to this release's workflow run and commit:

```bash
gh attestation verify radiogeddon-full-momentum.fap --repo mrSlime-man/RADIOGEDDON
```

`BUILD_INFO.txt` records the edition, app id, SDK, API, source revision and
embedded modules each artifact was built from.

## Known limitations

- Nothing new since beta 2 is verified on a device yet. How the dolphin reads
  on the real screen, the frame rate the firmware's GUI reaches, sounds and
  vibration, and the memory headroom with 15 KB more resident code are
  unchecked.
- The Full edition is about 15 KB larger in memory than beta 7. If a device
  is short of memory, choose *Classic* in Settings (it does not load the new
  views), and the app falls back to it by itself when less than 8 KB is free
  at start; the code itself stays resident either way.
- The lab room's radar and antenna are illustrations; only its oscilloscope
  (a saved recording) and terminal (counts from the SD card) show real data.
- The Catalog edition is not in the Apps Catalog yet: the submission needs
  qFlipper screenshots from hardware, and it has not been submitted.
- RadioGeddon does not recover keys, decrypt payloads or predict rolling
  codes, and refuses to replay decoded rolling-code protocols.
