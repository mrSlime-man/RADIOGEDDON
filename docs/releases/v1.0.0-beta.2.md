RadioGeddon v1.0.0 Beta 2

> [!IMPORTANT]
> **Corrected beta.** `v1.0.0-beta.1` crashes on launch on RogueMaster with
> "Flipper crashed and was rebooted — Out of memory". This release fixes that
> crash and replaces beta 1 as the recommended download.

> [!WARNING]
> This is still a pre-release. A tester has reported that the RogueMaster build
> launches and works on a physical Flipper Zero, but the
> [hardware checklist](https://github.com/mrSlime-man/RADIOGEDDON/blob/main/docs/HARDWARE_CHECKLIST.md)
> has not been worked through and logged, so nothing is independently verified
> on a device yet. Use only on devices you own or are authorized to test.

## What changed

**Fixed: out-of-memory crash on launch.** Beta 1 allocated about 110 KB of
radio state while starting up, before the main menu: a 64 KB RAW capture
buffer, the Sub-GHz protocol decoders and manufacturer keystore, and the radio
worker. On RogueMaster that exceeded the free heap. Now:

- The decoders, keystore and worker are created when you open **Receive &
  Record** or the **Frequency Hopper**, and freed when you leave.
- The RAW buffer is created when you start recording, sized to the free memory
  (up to 16,384 samples), and freed once the capture is saved.
- If there is not enough free memory to record, the LED blinks red and the app
  keeps running instead of crashing.

No features were removed. Full details: [CHANGELOG](https://github.com/mrSlime-man/RADIOGEDDON/blob/main/CHANGELOG.md).

## Which file do I download?

Install the build that matches your firmware. The others are safely refused by
the Flipper rather than loading.

| Firmware | File | API |
|----------|------|-----|
| Official (flipperzero.one) | `radiogeddon-official.fap` | 87.1 |
| Unleashed | `radiogeddon-unleashed.fap` | 88.9 |
| RogueMaster | `radiogeddon-roguemaster.fap` | 88.16 |

Copy it to `SD Card/apps/Sub-GHz/` (replacing beta 1 if you installed it) and
open **Apps → Sub-GHz → RadioGeddon**. Full steps:
[Installation](https://github.com/mrSlime-man/RADIOGEDDON/blob/main/docs/INSTALLATION.md).

## Verifying these downloads

`SHA256SUMS` is attached. Check it with `sha256sum -c SHA256SUMS` (Linux) or the
per-file commands in the installation guide. Each `.fap` also has a signed
build-provenance attestation linking it to this release's workflow run and the
tagged commit:

```bash
gh attestation verify radiogeddon-official.fap --repo mrSlime-man/RADIOGEDDON
```

`BUILD_INFO.txt` records the SDK, API and source revision each artifact was
built from.

## Known limitations

- Settings (frequency, modulation) are not persisted across launches.
- Internal CC1101 only; RAW capture capped at 16,384 samples, or fewer when
  memory is short (engine analysis uses the first 4,096).
