RadioGeddon v1.0.1 — Official 1.5.1 compatibility

RadioGeddon 1.0.1 is a compatibility patch for the Official Flipper Zero
firmware. Official 1.5.x moved its API major version from 87 to 88, so a
Flipper on Official 1.5.1 refuses v1.0.0's `radiogeddon-catalog-official.fap`
(built for API 87.1) with **"Outdated app"**. This release rebuilds the
Catalog edition against the Official 1.5.1 SDK (API 88.2).

Apart from the version string on the About screen, the application code is
1.0.0's: no feature was added or removed, every transmit restriction is
unchanged, and the four Full-edition builds are built from the same pins as
in 1.0.0. The v1.0.0 release stays as it was.

## What changed

- **Official SDK pin:** firmware **1.5.1**,
  `flipper-z-f7-sdk-1.5.1.zip` from `update.flipperzero.one`, SHA-256
  `dfde39df32ba8a9789b26afc1d702579ad8399a1c285770637cfe3287b2e2ffe`
  (the f7 `sdk_zip` entry in Official's update index, release channel),
  API **88.2**. Previously 1.4.3, API 87.1.
- **Firmware source pin** for the host tests: tag 1.5.1, commit `9e810dc`.
  The decoder tests follow the firmware's own Sub-GHz unit tests at 1.5.1,
  including its new Elplast decoder and capture.
- **Catalog `fap_version`** stays `1.0`, as in the first Apps Catalog
  submission.

## Who should update

| Your firmware | What to do |
|---|---|
| Official **1.5.1** (or a later 1.5.x) | Install this release's `radiogeddon-catalog-official.fap` |
| Official **1.4.x** | Keep v1.0.0's file, or update your firmware to 1.5.1 and use this one. This build does not load on 1.4.x |
| RogueMaster, Momentum, Unleashed | Nothing changed for you; the files below are the same builds as in 1.0.0 |

## Checked against Official 1.5.1

- The Catalog edition compiles against the 1.5.1 SDK without source
  changes; the SDK's `APPCHK` reports target 7, API 88.2; the manifest
  (name `RadioGeddon`, version 1.0, API 88.2, target f7) is verified, and
  all 305 imported symbols are exported by the 1.5.1 `api_symbols.csv`.
- What 1.5.1 removed from the API (USB CCID functions) is not used by the
  app. The preset enum gained `FuriHalSubGhzPreset2FSKDev12KAsync`, shifting
  later values; the app uses named constants from the 1.5.1 headers and
  stores presets by name. The radio's valid frequency ranges are unchanged.
- No API check is bypassed and no manifest is edited: the API version comes
  from the SDK the app is compiled with.

## Hardware testing — what is and isn't confirmed

**This build has not been run on a Flipper yet.** Whether the Catalog edition
launches on Official 1.5.1 is unconfirmed until the owner tests it on a
device. The hardware evidence for 1.0.0 (the Full edition on RogueMaster
`4f2e06200`) is unchanged; see
[VERIFICATION.md](https://github.com/mrSlime-man/RADIOGEDDON/blob/main/docs/VERIFICATION.md#reported-by-users-on-physical-hardware).
Use only on devices you own or are authorized to test.

## Build & verification

- Five builds from one source commit, built from scratch. For every
  artifact the API version is asserted, the manifest checked and every
  imported symbol resolved against that firmware's `api_symbols.csv`; for
  the four Full builds the same holds for each of the 19 embedded modules.
- Host unit tests under AddressSanitizer and UBSan; the firmware's own
  Sub-GHz decoders on its 1.5.1 test captures; format, capture,
  engine-lifecycle, fingerprint, activity-log, memory-stress and offline UI
  tests; ThreadSanitizer; libFuzzer on every file reader; firmware API
  contract checks; code-section checks; module load cost and heap-model
  replays; GCC `-fanalyzer` and clang-tidy; clang-format; the Apps
  Catalog's own rules and bundler on the Catalog edition.
- Automated checks are not device verification.

## Verifying these downloads

`SHA256SUMS` is attached. Check it with `sha256sum -c SHA256SUMS` (Linux) or
the per-file commands in the installation guide. Each `.fap` also has a
signed build-provenance attestation:

```bash
gh attestation verify radiogeddon-catalog-official.fap --repo mrSlime-man/RADIOGEDDON
```

`BUILD_INFO.txt` records the edition, app id, SDK or firmware commit, API,
source revision and embedded modules of each artifact.

## Known limitations

- The Catalog edition on Official 1.5.1 is verified by automation only.
- `radiogeddon-catalog-official.fap` from this release does not load on
  Official 1.4.x (API 87); v1.0.0's file still serves 1.4.x.
- The limitations listed for
  [1.0.0](https://github.com/mrSlime-man/RADIOGEDDON/blob/main/docs/releases/v1.0.0.md#known-limitations)
  still apply.
