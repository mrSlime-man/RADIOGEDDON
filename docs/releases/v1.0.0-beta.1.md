The first public build of **RadioGeddon**, a standalone Sub-GHz radio analysis
toolkit for the Flipper Zero — scan, hop, capture, identify, analyse, compare
and (where authorized) replay signals entirely on the device.

## Which file do I download?

Install the build that matches your firmware. The others are safely refused by
the Flipper rather than loading.

| Firmware | File | API |
|----------|------|-----|
| Official (flipperzero.one) | `radiogeddon-official.fap` | 87.1 |
| Unleashed | `radiogeddon-unleashed.fap` | 88.9 |
| RogueMaster | `radiogeddon-roguemaster.fap` | 88.16 |

Copy it to `SD Card/apps/Sub-GHz/` and open **Apps → Sub-GHz → RadioGeddon**.
Full steps: [Installation](https://github.com/mrSlime-man/RADIOGEDDON/blob/main/docs/INSTALLATION.md).
Not sure which firmware you have? See
[Firmware Compatibility](https://github.com/mrSlime-man/RADIOGEDDON/blob/main/docs/FIRMWARE_COMPATIBILITY.md).

## Features

Sub-GHz Scanner · Frequency Hopper · RAW Signal Capture · Protocol
Identification · Signal Analyzer · Unknown Protocol Analysis · Signal Comparison
· Device ID Candidate Detection · Rolling Code Classification · Cryptographic
Structure Heuristics · Signal Database · Authorized Signal Replay.

Every analysis result is labelled `[CONFIRMED]` (a firmware decoder matched),
`[HEURISTIC]` (a statistics-based guess) or `[HYPOTHESIS]` (an engine
inference). RadioGeddon does **not** recover keys, decrypt payloads, predict
rolling codes, or replay rolling-code remotes. Full list:
[Features](https://github.com/mrSlime-man/RADIOGEDDON/blob/main/docs/FEATURES.md).

## Verifying these downloads

`SHA256SUMS` is attached. Check it with `sha256sum -c SHA256SUMS` (Linux) or the
per-file commands in the installation guide. Each `.fap` also has a signed
build-provenance attestation linking it to this release's workflow run and the
tagged commit:

```bash
gh attestation verify radiogeddon-official.fap --repo mrSlime-man/RADIOGEDDON
```

`BUILD_INFO.txt` records the SDK, API and source revision each artifact was
built from.

## Known limitations

- No on-device verification yet.
- Settings (frequency, modulation) are not persisted across launches.
- Internal CC1101 only; RAW capture capped at 16,384 samples (engine analysis
  uses the first 4,096).
